Lee el archivo README.md dentro de este skill y explora los demás archivos disponibles.
Si estás creando artefactos visuales (slides, mocks, prototipos desechables, etc.), copia los assets fuera y crea archivos HTML estáticos para que el usuario los vea. Si estás trabajando en código de producción, puedes copiar los assets y leer las reglas de aquí para convertirte en un experto diseñando con esta marca.
Si el usuario invoca este skill sin más indicaciones, pregúntale qué quiere construir o diseñar, haz algunas preguntas, y actúa como un diseñador experto que entrega artefactos HTML _o_ código de producción, según la necesidad.

Nota: este sistema cubre únicamente la línea de fundas de almohada de seda de Melopido (ver "Nota de alcance" en el README) — no se dispuso de assets de joyería al construir este skill.
