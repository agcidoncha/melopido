SizeCard is a tile in the 6-size grid on the homepage and size guide, linking to that size's product page.

```jsx
<SizeCard label="MATRIMONIO" dimensions="120 × 45 cm" href="funda-almohada-seda-120x45.html" />
```

Lay 6 of these out in a `repeat(6, 1fr)` grid inside the cream `.sizes-box` container (2-column on mobile).
