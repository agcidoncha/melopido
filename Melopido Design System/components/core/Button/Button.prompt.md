Button renders melopido's link-styled CTAs — use for hero CTAs, header actions and product page purchase/guide actions.

```jsx
<Button variant="round" arrow href="#">Descubre nuestras fundas</Button>
<Button variant="amazon" href="#">Lo Quiero</Button>
<Button variant="guide" href="#">Instrucciones de uso</Button>
```

Variants: `round` (pink pill, hero CTA, optional `arrow`), `light` (white outline, header), `primary` (solid pink, header), `amazon` (orange commerce CTA with glow shadow), `guide` (neutral outlined CTA next to amazon button).
